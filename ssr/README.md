# 포켓몬 도감 - Server Side Rendering

이 디렉터리는 포켓몬 도감을 **Server-Side Rendering(SSR)** 방식으로
구현하는 공간입니다.

`/csr` 디렉터리의 구현을 기준으로,
애플리케이션을 서버에서 렌더링하도록 전환합니다.

---

## 진행 방법

SSR 전환은 `/steps` 디렉터리에 정의된 단계에 따라 진행합니다.

각 Step은 SSR 환경을 구성하기 위한 핵심 요소를 순차적으로 다룹니다.

예시 흐름:

1. 서버 엔트리와 클라이언트 엔트리 분리
2. Express 서버 구성 및 서버 렌더링
3. `hydrateRoot`를 이용한 클라이언트 하이드레이션
4. Hydration mismatch 해결
5. 서버 데이터 패칭과 클라이언트 전달
6. 서버 사이드 라우팅

각 단계를 완료할 때마다 커밋을 분리하여 전환 과정을 추적할 수 있도록 합니다.
각 단계에 대한 자세한 사항은 `/steps` 디렉터리 하위에 정의된 단계 문서를 참고하세요.

---

## 구현 시 고려 사항

- 서버와 클라이언트의 실행 환경은 다릅니다.
- 브라우저 전용 API(`window`, `document` 등)는 서버에서 사용할 수 없습니다.
- 서버에서 렌더링한 HTML과 클라이언트의 초기 렌더 결과는 동일해야 합니다.
- 서버에서 요청한 데이터를 클라이언트에 전달하여 초기 상태를 일치시켜야 합니다.

---

## 최종 목표

다음 조건을 만족하면 SSR 전환이 완료된 것입니다:

- 첫 번째 HTML 응답에 포켓몬 데이터가 포함됩니다.
- JavaScript를 비활성화해도 목록이 표시됩니다.
- Hydration 경고가 발생하지 않습니다.
- CSR 버전과 동일한 기능을 유지합니다.
